## 最小化暂停播放
- `native.rs` 加 `is_minimized(window)`（macOS NSWindow.isMiniaturized，非 macOS false）。
- `app.rs`：`App` 加字段 `resume_on_restore`；`tick` 顶部轮询 `native::is_minimized`——
  最小化且正在播就 `p.pause()` + 置位，还原后 `p.play()` 续播；`busy` 条件加 `|| min`
  让最小化期间帧循环不停；`stop()` 清标记。手动空格暂停不会被还原误续。
- 新增源码钉子 `minimize_pauses_playback`。`cargo test` 119 通过。

## 文件关联做扎实（默认音频视频用 iPlayer）
- 根因：mkv/avi/flv/rmvb/wma/ape 等 macOS 无系统 UTI，旧 `LSHandlerRank=Alternate` 也只声明大类，
  双击永远用别的播放器。
- `media.rs`：`DocType` 增 `set_utis`/`rank_default`；`doc_types_plist()` 现吐
  `UTImportedTypeDeclarations`（每个扩展名 `com.iplayer.<ext>` conform 到 public.movie/audio/image）
  + `CFBundleDocumentTypes`（音视频 `Default`、图片 `Alternate`）；`all_utis()` 只收音视频
  （大类+具体子类+自定义 UTI），图片排除。
- `check_default_player()` 启动首 tick 检测到非默认就**自动设一次**（幂等），装好即默认。
- `set_default_role_handler` 签名改 `&[String]`（all_utis 返回 Vec<String>）。
- 新增 `doc_types_plist_declares_custom_utis_and_default_rank` + `all_utis_covers_audio_video_not_images`。
- `bundle-macos.sh --install` 重装，`lsregister` 已认下全部 `com.iplayer.*` 类型。

## 文件关联第二版：std_uti 对齐 + 弹框风暴修复
- 实测 `--set-default` 后 mp4/mkv/wma 仍归 QuickTime/XLPlayer：根因二。
- ① `std_uti()` 映射错：之前拍脑袋写的 UTI 和系统实际不一致，导致 `LSSetDefaultRoleHandlerForContentType`
  对 mkv/wma/opus 吃 `paramErr(-50)` 跳过，其余设了也用的是错 UTI（mp4 写成 quicktime-movie 而非
  `public.mpeg-4`）。用 `UTTypeCreatePreferredIdentifierForTag` 在机器上查出真实 UTI 全部对齐，
  新增 `std_uti_matches_system_utis` 钉子防回退（mp4→public.mpeg-4、mkv→com.blurayplayersoftware.matroska、
  wma→com.microsoft.windows-media-wma、opus→org.xiph.ogg-audio 等）。
- ② 即便设对 UTI，仍有 9 种格式（mkv/m4v/avi/flv/wmv/wma/m2ts/ts/rmvb）双击还是开别的播放器：
  这些被 TV / XLPlayer / QuickTime 经 `LSHandlerRank=Default` 锁定，`LSCopyDefaultRoleHandlerForContentType`
  无论 Viewer 还是 All 角色都判给它，系统不让第三方静默覆盖。
- **弹框风暴根因**：`check_default_player` 在启动自动调 `LSSetDefaultRoleHandlerForContentType`，
  该 API 覆盖已有默认时**每个格式弹一次确认框**（".m4v 用 iPlayer 还是 TV？"），几十格式=几十次点击。
  用户截图正是这个框。
- **修复**：`set_default_role_handler` 改为**直接改写** `~/Library/Preferences/com.apple.LaunchServices/
  com.apple.launchservices.secure.plist` 的 `LSHandlers`，给每个 uti 写 `LSHandlerRoleAll = com.iplayer.app`
  （python3 读写，写完 `killall -u $USER cfprefsd`），**静默无框**。`native.rs` 留 C-API 兜底
  `set_defaults_via_lsapi`。`check_default_player` 判据由抽象 `public.movie` 改具体 `public.mpeg-4`。
- 结果：`cargo test` 120 通过；18 种常见格式（mp4/mov/mp3/m4a/aac/flac/ogg/opus/wav/webm/ape/ac3/…）
  静默默认 iPlayer；9 种锁定格式维持 TV/XLPlayer/QuickTime（要改只能用户手动"全部更改"一次性）。
- 验证：`NSWorkspace URLForApplicationToOpenURL:` 探针确认 18 种归 iPlayer；`LSCopyDefaultRoleHandler…`
  确认锁定格式仍归原主（符合预期、不弹框）。
