## 19:10 · Dock 关联主界面（关窗 = 藏窗口）

**用户诉求**：Dock 右键菜单加「显示主界面」；现在怎么点都不出主界面。
（旁证：bundle 脚本清出了 /Applications/iPlayer.app 的旧注册——用户跑的是旧拷贝。）

**机制**（读了 gpui-pre 0.3.8 / gpui-kit 0.7.1 源码）：
- gpui 的 `applicationShouldHandleReopen` 转发到 `Application::on_reopen`（**挂在
  Application 上**，run 之前注册；返回 &Self，要先绑定变量再 run，不能直接链式）。
- Dock 菜单项动作走 App::dispatch_action：有活跃窗口→窗口内 on_action；无→全局
  `App::on_action::<A>` 兜底。`is_action_available` 看全局监听表，注册了就不置灰。
- 实现：
  - `actions!(iplayer, [ShowMainWindow])` + `set_dock_menu([MenuItem::action("显示主界面")])`
  - **红绿灯关闭 = 藏窗口**：`window.on_window_should_close` 返回 false + native orderOut；
    播放列表/进度全保留。真正退出 = 右上角 X（cx.quit）。
  - `native::hide_window/show_window`（orderOut / orderFront+makeKeyAndOrderFront+
    activateIgnoringOtherApps(已标 deprecated，allow 压住)）。
  - MAIN_WINDOW: OnceLock<AnyWindowHandle>（open_window 返回 (AnyWindowHandle, Entity) 元组）。
  - 删掉了昨天的 on_window_closed→quit（窗口根本不会关了）。
- 71/71、GUI 冒烟存活、重打包 dist/iPlayer.app (108M)。
- **用户须知**：/Applications 里是旧拷贝，必须用 dist 覆盖安装（--install）才生效。
